大家好，歡迎回來，這裡是 i PAS，A I o T 應用工程師初級的有聲課，今天是第六天，模擬考日。今天的模擬考題都改編自官方學習指引的練習評量，範圍是考科一 1.1、1.2，還有 2.1 到 2.3。這集音檔不教新東西，而是帶你用最生動的方式，把最常考的點和陷阱再刷一遍，聽完就去計時作答。

先講作答技巧。i PAS 單選題很愛問「下列何者『不』正確」，請先圈出那個「不」字再看選項。不確定的題目用刪去法，先刪掉兩個明顯錯的。就像點飲料猶豫時，先排除你絕對不喝的，再從剩下的選。

第一站，考科一 1.1，A I 基礎。
口訣再念一次：有答案是監督，沒答案是非監督，給糖果是強化。考題常這樣問：「監督式學習不需標籤」，錯；「非監督式常用分群把相似資料歸類」，對；「強化學習主要做靜態影像瑕疵檢測」，錯，A O I 通常是監督式加 C N N；「迴歸屬於非監督」，錯，迴歸是監督式、輸出連續數值。
想像你是工程師，拿到馬達連續震動波形，要選網路架構，C N N 還是 R N N？時間序列，選 R N N 或 L S T M。C N N 看照片，R N N 追劇。G A N 用來生成，隨機森林是傳統機器學習，不是深度學習。
量化是 F P 32 轉 INT 8；N P U 推論專用、低功耗，不適合訓練；訓練在雲端、推論在邊緣；聯合學習只上傳模型參數，原始資料不離開本地。隱私由設計起始，P b D：在邊緣先去識別化。A I 是輔助判斷，不是最終決策者。
再補三個常見陷阱。邊緣運算的三大好處：快、省、私，低延遲、省頻寬、保隱私。小型語言模型 S L M 在邊緣可以做摘要和告警說明，但不直接介入設備控制邏輯。還有，A D C 類比數位轉換是訊號處理硬體，不是量化；增加網路層數只會更重，不是輕量化。

第二站，考科一 1.2，應用案例。
診斷分類，預測迴歸。「現在是哪種故障」是分類；「還能撐多久」是迴歸，輸出剩餘有效壽命 R U L。感測融合提升強健性，但成本可能增加。四位一體：感知、通訊、智慧、安全，安全指資訊安全，不是工廠保全。小情境：工廠裡有好幾個廠牌的 P L C，資料格式都不一樣，A I 要怎麼讀？透過閘道器轉成 O P C U A。大面積農場，選 LoRa 加端雲協作。

第三站，考科一 2.1，物聯網架構。
三層：感知、網路、應用，口訣「看、送、想」。陷阱一：超音波量距離，不是量分貝。陷阱二：P I R 偵測移動，人坐著不動就偵測不到。D H T 11 量溫濕度，M Q 2 量可燃氣體。O S I 七層，從上到下「應、表、會、傳、網、鏈、實」，表達層管加密和壓縮。

第四站，考科一 2.2，通訊協定。
M Q T T 是 T C P 加發布訂閱，Q o S 0 不保證送達，像寄平信。CoAP 是 U D P 加 REST，沒有 QUERY 這個方法。WebSocket 雙向即時。5G 不是低功耗長距離，那是 L P W A N；N B IoT 是窄頻，不適合影音；Matter 不支援 LoRa；S S I D 是基地台識別碼。
R F I D 頻段也很愛考：低頻動物門禁、高頻圖書護照、超高頻倉儲 E T C，一次讀數百個、微波追行李。N F C 固定 13.56 百萬赫茲，實務 4 公分內，三種模式：卡片模擬、讀卡機、點對點。想像你拿手機碰一下藍牙喇叭就配對好，這就是點對點的快速配對。Zigbee 協調器只能有一個，終端裝置不轉發。N B IoT 授權頻譜，LoRaWAN 非授權、可自建；指引說 N B IoT 不支援移動性，這是早期版本特性，但考試依指引作答。5G 三場景：e M B B 快、m M T C 多、U R L L C 準。
考題常這樣問：「下列何者不是 Matter 支援的傳輸？」答 LoRa。

第五站，考科一 2.3，工業通訊與網路。
T C P 連接導向、可靠，像掛號信；U D P 無連接、不保證，像發傳單。L A N 是小範圍網路；I P v 4 是四組數字。O P C U A 跨平台，不只 Windows。四種存取方式：讀寫、資料變更、方法、事件；題目說「訂閱特定事件、被動接收通知」，就是事件通知。M Q T T 的傳輸層是 T C P。
M Q T T 的 Q o S：0 丟了就算，1 一定到可能兩次，2 剛剛好一次，沒有 Q o S 3。裝置突然沒電，由 Broker 代發通知，是遺囑 L W T。MTConnect 三關鍵字：唯讀、X M L、H T T P。Modbus 四區塊：0 線圈、1 離散、3 輸入、4 保持，能寫的只有線圈和保持；R T U 配 C R C，A S C I I 配 L R C，T C P 常用 502 埠。RESTful：POST 成功回 201，DELETE 常回 204。
還有一個依指引作答的題型：H T T P 在伺服器回應後會斷線，Socket、WebSocket、F T P 不會。實際上這是 H T T P 1.0 的行為，但考試依指引答 H T T P。
另外，少數官方原題有排版或答案爭議，模擬考解析裡已經用警告符號標註，看到就以解析說明理解觀念。

好，熱身自測三題，每題念完你先在心裡作答。
第一題：馬達電流趨勢預測，該用 C N N 還是 L S T M？先想一想……好，答案是 L S T M，因為是時間序列。
第二題：M Q T T 的 Q o S 0 保證送達嗎？先想一想……好，答案是不保證，可能遺失。
第三題：超音波感測器量的是什麼？先想一想……好，答案是距離，不是噪音分貝。

最後回顧：監督、非監督、強化；C N N 空間、R N N 時間；N P U 只推論；診斷分類、預測迴歸；看、送、想；應表會傳網鏈實；M Q T T 走 T C P、CoAP 走 U D P；O P C U A 的事件通知。好，現在就打開模擬考，計時作答，交卷後錯題會自動進錯題本，明天一起整理。加油，我們明天見！
