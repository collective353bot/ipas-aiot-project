# Course video pipeline (HyperFrames)

Turns one day's narration mp3 + script + lecture notes into a 1920×1080 course video:
**align → segments → composition → render**. Built/tested on D2 (`d02/`).

```
video/
  align.py          # 1. ASR + script alignment  -> <day>/<day>.srt, <day>.segments.json
  build.py          # 3. slides.html + segments  -> <day>/index.html (HyperFrames composition)
  shared/theme.css  # look & feel shared by all days (dark theme, Noto Sans TC)
  shared/fonts/NotoSansTC.ttf, shared/gsap.min.js   # vendored locally (no CDN at render time)
  d02/
    slides.html     # 2. hand-authored slide spec for the day (content ONLY from study/src/dNN.md)
    d02.segments.json, d02.srt, asr_words.json, align_report.json, slides.timing.json
    index.html      # generated; hyperframes.json/package.json/meta.json = HyperFrames project files
    assets/         # generated by build.py (narration.mp3, font, gsap) — git-ignored
    d02.mp4, preview_60s.mp4, frames/*.png
```

## Requirements
- Node ≥ 22, `npx hyperframes` (tested 0.8.180), Chrome (`/usr/bin/google-chrome`), ffmpeg/ffprobe.
- Python venv for ASR: `python3 -m venv /workspace/.venv-asr && /workspace/.venv-asr/bin/pip install faster-whisper opencc-python-reimplemented soundfile`

## 1. Align (timecodes)
```bash
cd video
/workspace/.venv-asr/bin/python align.py --audio ../audio/v2/d03.mp3 --script ../audio/scripts_v2/d03.txt --out d03
```
- faster-whisper `small` (CPU int8, ~1 min for 13 min audio) with **`vad_filter=True, condition_on_previous_text=False`**
  (without these whisper silently skipped ~3 min of D2 audio and alignment collapsed).
- ASR is converted to Traditional (OpenCC s2t), both texts reduced to alnum chars, then char-level
  `difflib.SequenceMatcher`. Each subtitle chunk (script split at 。！？, long ones split at ，、： to ≤30 chars)
  takes start/end from its first/last matched char; unmatched chars are interpolated.
  **Subtitle text is always the script wording**, never ASR.
- `display()` cleans TTS spellings for the screen (`O S I`→`OSI`, `8 0 2 點 11 n`→`802.11n`, `I 平方 C`→`I²C`, …).
  Add new day-specific fixes to `DISPLAY_FIX` in align.py.
- Check `align_report.json`: `char_match_ratio` (D2: 93.3%) and `low_match_segments` (D2: none). ASR is cached in
  `asr_words.json`; delete it to re-transcribe. Do **not** use `audio/v2/raw/*.words.json` (pre-edit timings).

## 2. Slide spec (`<day>/slides.html`)
One `<section>` per slide:
```html
<section data-anchor="第三段" data-title="3. OSI 七層與 TCP/IP 四層" data-code="考科一 2.1｜指引 p.4-9～4-12">
  <div class="ol a" data-at="應用層是你要寄什麼">7 應用層 …</div>
</section>
```
- `data-anchor`: a phrase from the subtitles; the slide starts at the first segment containing it (searched forward).
- `data-at`: element fades/slides in (with a short yellow highlight) when that phrase is spoken (searched from the slide start).
  Phrases are matched against the cleaned subtitle text with whitespace removed.
- `data-code`: official 評鑑項目 code shown top-right. `data-kind="title"` = title card.
- Reusable classes in theme.css: `goals, pts, chips, mnemo, warn, note, layers/layer, tbl, osi, cards c3/c4, vs, flow, zig/roles, g5/tri, quiz, recap`.
  Inline SVG works for diagrams. Keep content strictly from `study/src/dNN.md`.

## 3. Build + check
```bash
python3 build.py d03          # warns about any anchor/data-at phrase not found
cp d02/{hyperframes.json,package.json,meta.json} d03/   # first time only (edit name/id)
cd d03 && npx hyperframes lint && npx hyperframes snapshot --at 30,120,300 --no-end -o /tmp/snap
```
Lint: 0 errors; the remaining warnings (nested_structure_needs_subcomposition, track density, file size) are
Studio-editing advice and don't affect rendering. Topbar topic text is set in build.py (`topic`) — change it per day.

## 4. Render
```bash
cd d03
# 60 s preview: copy project, cap durations
cp -r . /tmp/p && sed -i 's/data-duration="<FULL>"/data-duration="60"/g' /tmp/p/index.html && (cd /tmp/p && npx hyperframes render -o $PWD/preview_60s.mp4)
# full (detached so a tool timeout doesn't kill Chrome)
bash -c 'set -m; HYPERFRAMES_RENDER_DETACHED=1 npx hyperframes render -o d03.mp4 --fps 30 --quality looks < /dev/null > /tmp/render.log 2>&1 &'
# frames
for t in 5 90 260 420 568 765; do ffmpeg -v error -ss $t -i d03.mp4 -frames:v 1 frames/f_${t}s.png; done
```
D2 numbers (8 vCPU box, software GPU, beginframe capture): 60 s preview in 38 s; full 13:27 video in 7 min 14 s (3 workers), 56 MB H.264 CRF16 + AAC.
