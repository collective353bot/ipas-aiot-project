## 1. 智慧製造與 AIoT 的角色 {{考科二 2-3｜補充（依簡章評鑑內容 2-3）}}
- **智慧製造**：以設備聯網、資料分析與自動化，讓工廠從「事後處理」走向「即時可視、可預測、可自主調整」。常見概念：工業 4.0、**虛實整合系統（CPS）**、**數位雙生（Digital Twin，實體設備在虛擬世界的即時對應模型，可模擬與預測）**。
- **演進階段（記法）**：**看得見**（設備聯網、即時看板）→ **看得懂**（分析原因）→ **預測得到**（預測性維護、品質預測）→ **自主調整**（自動調參、最佳化排程）。

| AIoT 應用 | 改善的對象 |
|---|---|
| 設備聯網＋即時 OEE 看板 | 停機、小停機看得見，縮短反應時間 |
| 預測性維護（震動、電流、溫度） | 減少非計畫停機（可用率）與維修成本 |
| AI 視覺檢測（AOI） | 降低不良與漏檢（品質）、減少人工檢驗成本 |
| 能耗監控與需量管理 | 降低電費、碳排 |
| 製程參數監控與 SPC | 及早發現製程偏移，減少報廢 |
| 排程最佳化、數位雙生模擬 | 縮短換線與等待，提高產能 |

## 2. OEE 設備綜合效率 {{考科二 2-3｜補充（依簡章評鑑內容 2-3）}}
**OEE＝可用率（Availability）× 效能（Performance）× 品質（Quality，良率）**

| 指標 | 公式 | 對應的「六大損失」 |
|---|---|---|
| 可用率 | 實際運轉時間 ÷ 計畫生產時間 | ① 故障停機 ② 換線、調整（換模） |
| 效能 | （理想週期時間 × 總產出數）÷ 實際運轉時間 | ③ 小停機、空轉 ④ 速度降低 |
| 品質 | 良品數 ÷ 總產出數 | ⑤ 製程不良與重工 ⑥ 開機（啟動）損失 |

> **💡 計算例**：計畫生產 600 分鐘，停機 60 分鐘 → 運轉 540 分鐘，**可用率＝540÷600＝90 %**。理想週期時間 0.6 分鐘／件，實際產出 720 件 → 理想需要 432 分鐘，**效能＝432÷540＝80 %**。良品 684 件 → **品質＝684÷720＝95 %**。**OEE＝0.9×0.8×0.95＝68.4 %**。驗算：良品數 × 理想週期時間 ÷ 計畫時間＝684×0.6÷600＝68.4 % ✔。

> **⚠️ 易混淆**：「機台在跑但跑得比標準慢」是**效能**損失，不是可用率；「停下來換模」是**可用率**損失；「做出不良品」是**品質**損失。業界常引用「世界級 OEE 約 85 %」作為參考目標（經驗值，非標準規定）。


:::check 考科二 2-3
射出成型機每天早上開機後，前 30 模因溫度尚未穩定而做出不良品，必須報廢。依講義的 OEE「六大損失」，這屬於哪一項？會直接降低 OEE 的哪一個因子？
A. 換線調整；可用率
B. 速度降低；效能
C. 開機（啟動）損失；品質
D. 小停機；效能
= C
> 六大損失中，「製程不良與重工」與「開機（啟動）損失」都歸在品質因子。換線調整、故障停機扣可用率；小停機、速度降低扣效能。
:::

## 3. 精實生產（Lean）與現場改善 {{考科二 2-3｜補充（依簡章評鑑內容 2-3）}}
**七大浪費**（源自豐田生產方式）：

| 浪費 | 例子 |
|---|---|
| 過量生產 | 做得比需求多、比需求早（被視為最嚴重，會引發其他浪費） |
| 庫存 | 原料、在製品（WIP）、成品堆積，占空間與資金 |
| 搬運 | 不必要的物料移動 |
| 等待 | 人或機器等料、等指令、等維修 |
| 動作 | 作業員多餘的走動、彎腰、找工具 |
| 過度加工 | 超出客戶需求的加工或檢驗 |
| 不良（瑕疵） | 報廢、重工、客訴 |

（有些教材另加第八種「未善用員工的才能」。）

| 精實工具 | 意義 |
|---|---|
| **JIT 及時生產** | 在需要的時候、生產需要的數量 |
| **看板（Kanban）** | 以卡片或訊號實現**拉式（Pull）生產**，由後工序向前工序領料 |
| **自働化（Jidoka）／安燈（Andon）** | 異常時自動停機並亮燈通知，不讓不良流到下一站 |
| **防呆（Poka-yoke）** | 設計上讓錯誤不可能發生或立即被發現 |
| **5S** | 整理（區分要與不要）、整頓（定位）、清掃、清潔（維持制度化）、素養（養成習慣） |
| **SMED 快速換模** | 把換線工作盡量改為機台運轉中就能準備（外部作業），縮短換線時間 |
| **TPM 全員生產保養** | 全員參與、作業員自主保養，目標零故障 |
| **價值流圖（VSM）** | 畫出從原料到交貨的物流與資訊流，找出浪費 |
| **改善（Kaizen）** | 持續的小幅改善 |


:::check 考科二 2-3
現場觀察發現，作業員每次換刀都要走到 20 公尺外的工具櫃找扳手，還常要彎腰翻找。依精實生產的七大浪費，這主要屬於哪一種？
A. 過量生產
B. 動作
C. 庫存
D. 過度加工
= B
> 作業員多餘的走動、彎腰、找工具＝動作浪費（可用 5S 的整頓改善）。過量生產是做太多太早；庫存是物料堆積；過度加工是超出客戶需求的加工或檢驗。
:::

A. 防呆（Poka-yoke）

> 防呆是「從設計上讓錯誤不可能發生或立即被發現」。JIT 是在需要時生產需要的量；VSM 是畫出物流與資訊流找浪費；TPM 是全員參與的設備保養。

## 4. 製造資訊系統分層（ISA-95） {{考科二 2-3｜補充（依簡章評鑑內容 2-3）}}
| ISA-95 層級 | 系統 | 時間尺度 | 負責 |
|---|---|---|---|
| Level 4 企業 | **ERP** | 月、週、日 | 訂單、採購、庫存、財務、主生產計畫 |
| Level 3 製造營運 | **MES** | 日、班、時 | 派工、生產追蹤與履歷、品質、在製品、績效（OEE） |
| Level 2 監控 | **SCADA、HMI** | 分、秒 | 監看、警報、操作 |
| Level 1 控制與感測 | **PLC**、感測器、致動器 | 秒、毫秒 | 即時控制與量測 |
| Level 0 | 實體製程 | — | 實際生產 |

IoT 資料由下往上整合（例如以 OPC UA 從 PLC 取值送到 MES），讓 ERP 的計畫與現場實績能即時對齊。

## 5. 流程優化方法與品質工具 {{考科二 2-3｜補充（依簡章評鑑內容 2-3）}}
- **PDCA**：計畫（Plan）→ 執行（Do）→ 檢查（Check）→ 行動（Act），持續循環改善。
- **DMAIC**（六標準差）：定義（Define）→ 量測（Measure）→ 分析（Analyze）→ 改善（Improve）→ 管制（Control）。
- **SPC 統計製程管制**：以**管制圖**監控製程，中心線為平均值，**管制上下限常取平均值 ± 3 個標準差**；點超出管制界限或出現連續偏向一側等異常樣式時，代表有特殊原因需要處理。
- **魚骨圖（特性要因圖）**：從**人、機、料、法、環**（4M1E，有時加「測」）找原因。
- **柏拉圖（Pareto）**：把問題依發生次數由大到小排列，找出造成約 80 % 問題的少數關鍵原因（80／20 法則）。
- **瓶頸（限制理論 TOC）**：整條產線的產出由**最慢的站（瓶頸）**決定，改善非瓶頸站無法提高總產出。
- **節拍時間（Takt Time）＝可用生產時間 ÷ 客戶需求量**：例如每日可用 450 分鐘、需求 900 件 → 每 0.5 分鐘（30 秒）要完成一件。若某站**週期時間（Cycle Time）**大於節拍時間，就跟不上需求。

## 6. 成本控制與投資評估 {{考科二 2-3｜補充（依簡章評鑑內容 2-3）}}
| 概念 | 說明 |
|---|---|
| 固定成本／變動成本 | 廠房折舊、租金不隨產量變動；材料、計件工資隨產量變動 |
| 損益平衡點（數量） | 固定成本 ÷（單價 − 單位變動成本） |
| **CAPEX 資本支出** | 一次性購置：設備、伺服器、感測器硬體（分年折舊） |
| **OPEX 營運支出** | 持續性費用：雲端訂閱、電信費、維護人力、電費 |
| **TCO 總擁有成本** | 購置＋建置整合＋維運＋能源＋教育訓練＋汰換，**不只看採購價** |
| **ROI 投資報酬率** | （效益 − 成本）÷ 成本 × 100 % |
| 回收期（Payback） | 初始投資 ÷ 每年淨效益 |
| 品質成本 | 預防成本、鑑定成本、內部失敗（報廢、重工）、外部失敗（退貨、保固、商譽）；**愈早預防通常總成本愈低** |

> **💡 計算例**：導入預測性維護投資 200 萬元，每年減少停機與維修損失 80 萬元 → **回收期＝200÷80＝2.5 年**；三年總效益 240 萬，**三年 ROI＝（240−200）÷200＝20 %**。

> **⚠️ 易混淆**：把自建伺服器改成雲端訂閱，是把 **CAPEX 轉成 OPEX**，初期投資降低，但長期總成本要用 TCO 比較，不一定比較便宜。
